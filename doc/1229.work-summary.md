# 工作总结

## 范围
- 拓扑还原插件（IB/RoCE）渲染、过滤、布局、交互与 UI 优化
- 高性能渲染（Cytoscape）显示与性能问题修复
- AI 工具箱插件归档到 `src/plugins`

## 关键修复
- IB/RoCE 统一支持 CSV/XLSX 上传，后端解析按扩展名自动分流
- Rail/POD 过滤逻辑恢复，IB 下 Rail 识别兼容前导零和分隔符
- Cytoscape 节点标签显示设备名，解决高性能模式名称丢失
- IB Spine 点击仅显示相关 Core 与连线，满足高密度场景聚焦需求
- LOD 视图切换（概览/分组/细节）+ 缩放自动切换（滞回阈值）
- Rail 切换触发布局/视图更新，ReactFlow 与 Cytoscape 过滤一致
- 聚合 POD 节点布局改为质心定位，减少布局告警
- 右侧详情面板 DOM nesting 警告修复
- HMR Fast Refresh 问题修复（`pluginMeta` 拆分文件）

## 布局与视觉优化
- IB 高性能布局按 Rail + POD 分列，提升结构可读性
- Cytoscape 节点尺寸、间距与层级高度压缩，显示密度提升
- UI 统一企业级视觉风格：卡片层级、色彩体系、字体与背景
- LOD 控制区、上传区、控制面板与信息侧栏一致化

## 代码结构调整
