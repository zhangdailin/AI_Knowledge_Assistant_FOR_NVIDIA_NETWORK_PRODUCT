# 2025-12-31 知识库优化记录

## 分块与上下文增强
- `server/chunking.mjs` 现支持传入 `documentType`、父级/兄弟上下文以及可选的段落摘要。
- Chunk 元数据新增 `parentHeader`、`siblingHeaders`、`sectionBreadcrumbs`、`sectionDepth` 与 `context` 字段，查询时可利用这些结构做更精准的 rerank。
- 上传流程 (`server/index.mjs`) 会把文档所属分类带入 chunking，后续可根据分类调整检索策略。

## 答案验证落地
- 新增 `server/answerValidation.mjs`，通过解析回答中的代码块/命令行，比对参考文档，输出 `isConsistent`、`confidenceScore`、`hallucinations` 等指标。
- `/api/chat` (SiliconFlow/Gemini) 在生成回答后自动调用验证函数，并在响应体中返回 `validation`。
- 前端 `ChatInterface` 为每条回答提示置信度并标记疑似幻觉命令，方便人工复核。

## 用户反馈闭环
- `/api/feedback`：接收"有帮助/待改进"反馈，写入 `data/feedback.json`，最多保存 2000 条。
- `/api/metrics/feedback`：返回反馈总量、正负面数量、近期列表等指标，便于后续做 Dashboard。
- 前端聊天消息提供点赞/点踩按钮，并把关联问题、答案和验证置信度一起上报，便于线下分析。

## 2026-01-01 进一步优化

### 答案验证算法优化
- **模糊匹配增强**：支持命令主体匹配和前缀匹配，允许参数差异（如 `netq show` 可匹配 `netq show agents`）
- **命令模式扩展**：新增对更多网络设备、Linux系统、网络工具和文件操作命令的识别
- **置信度计算改进**：
  - 基于命令匹配率和匹配质量的综合评分
  - 区分精确匹配（100%）、主体匹配（80%）、前缀匹配（70%）
  - 引入幻觉惩罚机制，提高评分准确性
- **部分匹配支持**：新增 `partialMatches` 字段，记录部分匹配的命令及其置信度

### 前端验证结果展示增强
- **交互式验证详情弹窗**：
  - 点击置信度标签可查看完整验证详情
  - 可视化展示置信度评分和进度条
  - 分类展示已验证命令、部分匹配命令、待核实命令
  - 显示警告信息和分析时间
- **改进的UI设计**：
  - 使用颜色编码区分不同验证状态（绿色=已验证，蓝色=部分匹配，黄色=待核实）
  - 添加 Info 图标提示用户可点击查看详情
  - 悬停效果和阴影增强交互体验

### 反馈数据分析Dashboard
- **新增反馈分析页面** (`src/components/FeedbackAnalytics.tsx`)：
  - 核心指标卡片：总反馈数、正面反馈、负面反馈、满意度
  - 满意度分布可视化（进度条展示）
  - 最近10条反馈详情列表
  - 自动刷新机制（每30秒）
  - 低满意度时显示改进建议
- **集成到管理后台**：
  - 添加 `/admin/feedback` 路由
  - 在侧边栏导航中新增"反馈分析"入口
  - 使用 MessageSquare 图标标识

### 技术改进
- **类型安全**：更新 `src/lib/types.ts` 支持新的验证字段（`partialMatches`）
- **本地存储增强**：`localStorage.ts` 新增 `updateMessageMetadata` 方法支持更新消息元数据
- **API扩展**：
  - `/api/feedback` - 提交用户反馈
  - `/api/metrics/feedback` - 获取反馈统计数据
