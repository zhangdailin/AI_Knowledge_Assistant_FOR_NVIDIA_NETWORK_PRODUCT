### 2. 文档质量评分系统

**目标**：多维度评估文档质量，优先推荐高质量内容

**实现文件**：`server/documentQuality.mjs` (338行)

**评分体系**：5维度，总分100分

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| **完整性** | 20分 | 文件大小、chunk数量、平均chunk长度 |
| **结构性** | 20分 | 标题层级、代码块、Breadcrumbs |
| **技术内容** | 25分 | 技术术语密度、命令示例数量 |
| **用户反馈** | 20分 | 正负反馈比例（90%+ = 20分）|
| **时效性** | 15分 | 文档上传时间（<30天 = 15分）|

**质量等级**：
- **S级**：90-100分（优秀）
- **A级**：80-89分（良好）
- **B级**：70-79分（中等偏上）
- **C级**：60-69分（中等）
- **D级**：50-59分（及格）
- **E级**：<50分（不及格）

**评分算法示例**：
```javascript
// 技术内容评分 (最高25分)

  ...
];

// 术语密度: 20+ terms = 15分
// 命令示例: 20+ commands = 10分
// 总计最高25分
```

**健康评分算法**：
```javascript
function calculateHealthScore() {
  let score = 100;

  // 1. 缓存命中率 (权重30%)
  if (cacheHitRate < 30%) score -= 30;
  else if (cacheHitRate < 50%) score -= 15;
  else if (cacheHitRate < 70%) score -= 5;

  // 2. 平均响应时间 (权重40%)
  if (avgTime > 5000ms) score -= 40;
  else if (avgTime > 3000ms) score -= 25;
  else if (avgTime > 2000ms) score -= 15;
  else if (avgTime > 1000ms) score -= 5;

  // 3. 内存使用 (权重30%)
  if (heapUsed > 1024MB) score -= 30;
  else if (heapUsed > 768MB) score -= 20;
  else if (heapUsed > 512MB) score -= 10;

  return Math.max(0, Math.min(100, score));
}
```

## 🐛 发现并修复的问题

### Bug #1: 语义缓存访问错误

**错误信息**：
```
TypeError: semanticCache.entries is not a function or its return value is not iterable
    at findSimilarCachedQuery (file:///D:/Github%20Code%20HUB/AI_Knowledge_Assistant/server/index.mjs:80:54)
```

**根本原因**：
`SimpleLRUCache` 类未暴露 `entries()` 方法，内部使用 `this.cache` (Map) 存储数据。

**修复方案**：
修改 `server/index.mjs:80-82`

**修复前**：
```javascript
// 遍历语义缓存
for (const [cacheKey, cacheEntry] of semanticCache.entries()) {
  const { queryEmbedding: cachedEmbedding, query: cachedQuery, results, timestamp } = cacheEntry;
```

**修复后**：
```javascript
// 遍历语义缓存 (访问内部的 Map)
for (const [cacheKey, cacheEntry] of semanticCache.cache.entries()) {
  const entry = cacheEntry.value || cacheEntry; // 兼容SimpleLRUCache的包装结构
  const { queryEmbedding: cachedEmbedding, query: cachedQuery, results, timestamp } = entry;
```

**影响范围**：
- 语义缓存功能无法使用
- 搜索请求会抛出异常

**验证**：
✅ 修复后服务器正常启动
✅ 模块测试通过

## 🔄 集成流程

### 查询扩展集成

```
用户查询
  ↓
检测是否启用查询扩展 (retrievalConfig.enableQueryExpansion)
  ↓
生成查询变体 (smartQueryRewrite)
  ↓
并行搜索所有变体
  ├─ 关键词搜索
  └─ 向量搜索
  ↓
结果去重（保留最高分）
  ↓
RRF融合
  ↓
Rerank重排
  ↓
返回结果
```

### 性能监控集成

```
搜索请求开始
  ↓
记录开始时间 (requestStartTime = Date.now())
  ↓
检查缓存
  ├─ 命中 → recordSearchRequest(duration, true, cacheType, 1)
  └─ 未命中 → 继续搜索
      ↓
    执行查询扩展、检索、融合、重排
      ↓
    recordSearchRequest(duration, false, null, variantCount)
```
