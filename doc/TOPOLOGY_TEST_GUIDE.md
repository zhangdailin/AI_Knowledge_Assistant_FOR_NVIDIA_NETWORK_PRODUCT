### 2. 测试清单

#### 2.1 后端测试

**CSV解析测试 (IB Network)**

□ 测试有效的UFM CSV格式
  - 验证System列正确识别
  - 验证Peer Node列正确识别
  - 验证端口信息(Port, Peer Port)正确提取
  - 验证BOM字符被正确处理

□ 测试边界情况
  - 空CSV文件处理
  - 缺少列头的CSV
  - 包含NaN或空值的行
  - 重复的连接关系

**Excel解析测试 (RoCE Network)**

□ 测试有效的NetQ Excel格式
  - 验证列名识别(Hostname, Interface, Peer Hostname, Peer Port等)
  - 验证多表单处理
  - 验证GPU设备过滤

**自动层级检测测试**

```javascript
// 验证度数分析
const testPortMap = new Map([
  ['CORE-001|1', { peer: 'SPINE-001', peerPort: '1' }],

  ['SPINE-001|1', { peer: 'LEAF-001', peerPort: '1' }],
```

**POD分组测试**

□ 正则表达式匹配
  - Pattern: `POD\d+` → 应匹配 POD1, POD2, POD-001等
  - Pattern: `[A-Z]\d{2}` → 应匹配 G01, G02等

□ 前缀匹配
  - prefixLength=2, delimiter='-' → MDC-DH1E-POD1-... → MDC-DH1E

□ 无分组
  - 所有设备归入ALL组

### 3. 测试用例

#### 用例1: 基本IB拓扑还原

**输入**: UFM导出的CSV文件
```csv
System,Port,Peer Node,Peer Port
MDC-DH1E-POD1-G01-IBLF-001,1,MDC-DH1E-POD1-G01-IBSP-001,1
MDC-DH1E-POD1-G01-IBSP-001,1,MDC-DH1E-IBCR-001,1
...
```

**操作**:
1. 选择网络类型: IB
2. 配置: 自动检测 + 正则表达式(POD\d+)
3. 上传文件

**期望结果**:
- ✓ 自动识别3层(Core/Spine/Leaf)
- ✓ 按POD1/POD2/...分组
- ✓ 节点数 = Core + Spine + Leaf数量
- ✓ 边数 = 三设备链路数量

#### 用例2: RoCE网络拓扑还原

**输入**: NetQ导出的Excel文件
```
Hostname,Interface,Peer Hostname,Peer Interface
ASW-POD1-001,Eth1,SSW-POD1-001,Eth1
SSW-POD1-001,Eth1,CSW-001,Eth1
...
```

**操作**:
1. 选择网络类型: RoCE
2. 配置: 自动检测 + 前缀匹配(length=2)
3. 上传文件

**期望结果**:
- ✓ 自动识别网络层级
- ✓ 按前缀分组
- ✓ 正确显示ASW/SSW/CSW设备

#### 用例3: 手动层级配置

**操作**:
1. 选择"手动配置"
2. 输入自定义正则:
   - Core: `IBCR|CORE`
   - Spine: `IBSP|SPINE`
   - Leaf: `IBLF|LEAF`
3. 上传文件

**期望结果**:
- ✓ 按指定模式识别层级
- ✓ 不在任何模式中的设备被分类为unknown

### 5. 常见问题排查

**问题**: 节点重叠
**解决**: 调整导出CSV中的POD命名规则，确保层级识别正确

**问题**: 边无法显示
**解决**: 检查Peer Node列值是否与System列值完全匹配（包括大小写）

**问题**: POD分组不工作
**解决**: 验证设备名称中确实包含匹配的POD标识符

**问题**: 自动层级检测不正确
**解决**: 使用手动配置指定自定义的正则表达式模式
